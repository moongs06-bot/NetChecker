# NetChecker AI Agent 디펜더 0.2

Windows 서버·중요 PC용 보안 감지, AI 근거 검토, 승인 조치 및 재검증 프로그램입니다.
현재 구현은 백신/EDR의 대체재가 아닌 관리 보조 제품입니다. AI를 사용한 공격인지 확정하지 않습니다.

## PC 전용 화면
바탕화면 `NetChecker AI Agent 디펜더`를 실행합니다. 다음 로그인부터 트레이로 실행됩니다.
현재 수집 상태, Windows Defender·방화벽 상태, 최근 이벤트, CPU·메모리·디스크 사용률, AI 검토, 조치 이력을 표시합니다.
미수집·승인 대기·등록 해제·지연 상태는 정상/방어 성공으로 표시하지 않습니다.
CPU·메모리·디스크 값은 기존 NetChecker 수집 자료이며, SMART 고장 진단이나 랜섬웨어 차단 결과가 아닙니다.
일반 사용자용 UI에는 인증키나 조치 실행 증명값이 저장되지 않습니다.

## 실제 감지 근거
Security 4625 로그인 실패, 1102 감사 로그 삭제; Defender Operational 1116 감지, 1117 조치, 5001 보호 중지.
최근 10분 같은 출처 로그인 실패 10회 이상 등을 점검 신호로 표시합니다. 동일 레코드는 중복 집계하지 않습니다.
서버의 허용 포트 기준이 설정되어 있으면 기존 5156/5157 관측 자료에서 기준 밖 접속을 표시합니다.
감사 정책 미확인, 기록 누락, 로그 조회 한도, 타사 백신 사용 여부 등은 별도로 확인해야 합니다.
AI는 집계 신호와 수집 범위를 검토해 우선 점검 순서를 제안합니다. AI가 조치를 승인하거나 명령을 생성·실행하지 않습니다.

## 패치 제안 → 승인 → 실행 → 재검증
1. Windows Update Agent API로 현재 장비의 미설치 보안/중요 업데이트를 조회합니다 (매시간, 읽기 전용).
2. 관리자는 중앙 대시보드에서 실제 조회된 UpdateID·Revision에 대해 조치를 제안합니다.
3. 대상 장비, 서비스 영향, 복구 가능한 백업을 확인하고 실행 가능 시간을 승인합니다. 승인 후 수령 가능 시간은 2시간입니다.
4. 장비는 Windows Update의 적용 가능 여부와 분류를 다시 확인하고, 승인한 항목만 내려받아 설치합니다.
5. 설치 결과, IsInstalled, 재부팅 필요 상태를 다시 읽습니다. 재부팅이 필요하면 추가 확인으로 남깁니다.
6. 관리자가 작업 시간에 재부팅·서비스 상태를 확인한 뒤 `적용 상태 재검증`을 요청할 수 있습니다.

자동 재부팅, 자동 라이선스 동의, 웹에서 찾은 EXE/스크립트 실행, AI 생성 명령 실행은 없습니다.
백업은 관리자의 확인 사항이며 이 프로그램이 백업을 만들거나 복구 가능성을 검증하지 않습니다.
OS 패치의 자동 제거/롤백은 제공하지 않습니다. 호환성 및 업무 서비스 확인은 현장 검증이 필요합니다.

## 임시 IP 차단 및 해제
첫 버전은 최근 24시간 로그인 실패 근거가 있는 단일 공인 IPv4만 제안 가능합니다.
내부망·루프백·관리 주소 범위, 현재 관리자 웹 접속 IP, 넷체커 제어 서버 주소는 차단 대상에서 제외합니다.
관리자 승인 후 인바운드 규칙을 만들고 정확한 규칙을 다시 읽어 적용 상태를 확인합니다.
차단은 60분간이며 별도 만료 작업이 약 30초 간격으로 해당 제품의 규칙만 정리합니다. PC가 꺼진 동안에는 정리가 실행되지 않으며, 다음 시작 시 다시 확인합니다.
원하는 경우 소유한 규칙의 해제도 제안·승인할 수 있습니다. 정상 이용자의 접속 영향은 관리자가 확인해야 합니다.
규칙 적용 확인은 공격 종료나 침입 차단 효과를 입증하지 않습니다.

## 중복 실행·오류 처리
승인 없는 조치는 장비가 수령할 수 없습니다. 장비별 키로 대상 범위를 검증하고, 수령 증명으로 결과를 확인합니다.
조치를 한 번 수령하면 자동으로 재수령하지 않습니다. 6시간 이후 결과 미확인으로 표시하며, 변경 작업은 재검증으로 해소하기 전 새로 실행하지 않습니다.
조치 결과 업로드가 실패하면 보호된 로컬 파일에서 재전송합니다. 조치 자체를 다시 실행하지 않습니다.
예기치 않은 재부팅 등으로 결과가 사라지면 관리자가 읽기 전용 재검증을 요청해야 합니다.
등록이 해제된 장비의 명시적 재설치는 새 키로 재등록할 수 있지만 기존 승인을 복구하지 않습니다.

## 공식 보안 권고
중앙 화면에서 CISA KEV의 Microsoft 관련 권고를 조회할 수 있습니다. HTTPS 고정 URL, 크기 제한, 필드 검증, 6시간 캐시를 사용합니다.
권고는 일반 참고 정보이며 해당 PC가 취약하다는 판정이나 CVE-KB 매칭을 제공하지 않습니다. 통신 실패는 미확인 또는 이전 자료로 표시합니다.
권고 원문은 실행 명령으로 취급하지 않습니다.

## 설치·실행 작업
Windows x64 / .NET Framework 4.8 / 관리자 설치 권한이 필요합니다.
NetCheckerDefender (수집), NetCheckerDefenderActions (승인 조치), NetCheckerDefenderExpiry (독립 만료 정리), NetCheckerDefenderInventory (읽기 전용 업데이트 조회).
일반 NetCheckerCollector는 유지합니다. 신규 등록은 관리자 승인 후 수집합니다.
클라이언트 비밀 정보: %ProgramData%\NetChecker 및 NetCheckerDefender (SYSTEM/관리자 전용).
화면 전용 상태와 실행 파일: %ProgramData%\NetCheckerDefenderStatus (일반 사용자 읽기/실행 전용).

## 검증 및 출시 범위
API 인증·대상 범위·승인/취소/만료·중복 실행 방지·재부팅 확인 보류·읽기 전용 재검증을 테스트합니다.
Windows 조치는 모의 COM/방화벽으로 확인합니다. 실제 PC에 패치를 설치하거나 IP를 차단하는 실환경 시험은 별도 승인 및 점검 시간에 진행해야 합니다.
상용 EDR 수준의 프로세스 메모리 분석·랜섬웨어 행동 차단·공격자 AI 사용 판별·서비스 정상성 자동 판정은 제공하지 않습니다.

## 확장 방향
전사 자산 목록과 중요도를 연결하고, 장비별 업무 시간·담당자·백업·허용 접속 기준을 관리할 수 있습니다.
향후 MSRC/NVD/CISA 자료와 정확한 제품 버전을 대조하고, 승인 템플릿·점검 시간·조치 전후 통신 및 서비스 지표를 확장할 수 있습니다.

## AI 디펜더 0.3 시간별 보안 보고

AI 디펜더 모니터링은 통신량·포트 분석과 독립된 메뉴입니다. 설치된 Windows 서버 또는 중요 PC에서 약 1시간마다 보안 상태·이벤트를 전송합니다. 중앙 서버가 날짜별 집계와 별도의 AI 보안 해석을 생성해 새 일일보고서·PDF에 포함합니다. 네트워크 AI 실패 때도 보안 집계는 보존하며 보안 AI 실패는 미완료로 표시합니다. 과거 보고서를 자동 재작성하거나 누락 자료를 생성하지 않습니다.

시간별 표본은 연속 보호 증거가 아닙니다. 로그인 실패·로그 삭제·Defender 이벤트, 백신·방화벽 상태, 조회된 보안·중요 업데이트 및 당일 생성 조치의 보고 시점 상태를 구분합니다. 미확인 정책과 수집 제한을 함께 표시하며 장비명/IP는 보안 AI 집계 입력에서 제외합니다. 임시 차단·패치 실행과 재검증 제어 요청은 보안 관측 자료 전송 주기와 별도입니다.

등록 해제된 장비의 목록에서 삭제 기능은 화면 목록에서 숨기며 인증 해제 상태와 과거 관측·보고서 기록을 보존합니다. 빠른 검사·전체 검사는 사용자 확인과 UAC 승인을 거쳐 기존 Windows Defender 엔진을 실행합니다. 다른 백신 때문에 비활성 상태이면 설정을 강제로 바꾸지 않습니다. 상세 검사 결과는 Windows 보안의 보호 기록에서 확인합니다.

2026-10-04 서버 격리 회귀 검사 통과: 시간대 경계·보안 집계, 등록 해제 장비 숨김, 네트워크 AI 실패 중 보안 근거 보존 및 기존 인증·수집·PDF·승인 작업 검사. 실제 악성코드, 방화벽 차단, 보안패치는 검증 중 실행하지 않았습니다. 디펜더 현장 수집은 1대이며 기존 43대 운영 수집 시범과 구분합니다.
